# Genora: серый бордоматик v1

Сырой 3D-превиз ролика «Genora перелетает нейронки на пшиках». Сцена целиком собирается скриптом в Blender, генерации и кредиты не нужны.

## Файлы

| Файл | Что это |
|---|---|
| `genora_boardomatic.blend` | Сцена Blender 4.5 (открывается и в 5.x), все текстуры упакованы внутрь |
| `genora_boardomatic_cuts.mp4` | Монтажная версия: 8 планов с разных ракурсов, как в рефе с Roadster |
| `genora_boardomatic_onetake.mp4` | Один непрерывный план «с телефона с трибуны», как в промпте Magnific |
| `build_scene.py` | Скрипт, который строит всю сцену: трек, рампу, ферму, иконки, Genora, анимацию и камеры |
| `make_textures.py` | Делает лицевые текстуры иконок (целая, с трещинами, глитч) из оригинальных иконок |
| `icons/` | Оригинальные иконки приложений из проекта Maksym в Magnific |
| `refs/` | Кадры-референсы: ключевой момент (5 с), Genora крупно, скетч раскладки, рампа из рефа |

## Тайминг (24 fps, 360 кадров, 15 с)

| Время | Что происходит | План (монтаж) |
|---|---|---|
| 0–2 с | Genora стоит на старте, ряд иконок, рампа вдали | SH01_Start |
| 1–3 с | три коротких пшика, пар по асфальту, взлёт | SH02_Puffs_LowFront |
| 3–5 с | пролёт над рядом, удар по ChatGPT | SH03_Lineup_FirstHit |
| 5–7,8 с | Claude, Gemini, DeepSeek, Grok падают по очереди и трескаются | SH04_KeyMoment |
| 7,8–9 с | Genora садится на дорогу перед рампой | SH05_OverTheRow |
| 9–12 с | разгон, рампа вверх, вверх ногами по верхней секции, вылет с открытого конца | SH06_Loop_Wide |
| 12–13 с | переворот на 180° в воздухе | SH07_Roll_LowUp |
| 13–15 с | пролёт над разбитыми иконками (глитчат), посадка в дым | SH08_Landing |

Удары по иконкам приходятся на кадры: ChatGPT 109, Claude 126, Gemini 142, DeepSeek 159, Grok 180.

## Как открыть и поправить

1. Открыть `genora_boardomatic.blend` в Blender.
2. Сцены переключаются вверху справа: `Boardomatic_Cuts` (монтаж) и `Boardomatic_OneTake` (один план).
3. В монтаже камеры переключают маркеры на таймлайне (SH01…SH08). Чтобы сдвинуть склейку, двигайте маркер.
4. Анимация Genora висит на объекте `GENORA`, струи называются `Genora_Jet_*` (длина струи задаётся scale Z).
5. Иконки называются `SLAB_<имя>`. Состояния лица (целая, трещины, глитч) переключаются через scale 0/1 у `Face_clean`, `Face_cracked` и `Face_glitch`.
6. Рендер стоит на Workbench (серый превиз). Если переключить на EEVEE, будет нормальный свет: эмиссия у LED, прожекторов, струй и лого уже настроена.

## Пересобрать с нуля

```bash
python3 make_textures.py icons textures
blender -b --factory-startup -P build_scene.py -- genora_boardomatic.blend
```
