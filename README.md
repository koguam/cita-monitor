# cita-monitor

Telegram-уведомления о свободных слотах **cita previa** в испанской
Sede Electrónica (Extranjería / CNP).

Настроен на **Таррагону**, трámite
**POLICÍA TARJETA CONFLICTO UCRANIA** (`4112`) — карта для перемещённых лиц
из Украины.

Бот **только проверяет наличие** слотов и присылает уведомление.
Он ничего не бронирует: выбор времени и подтверждение SMS-кодом остаются
ручным шагом.

## Как это работает

Сайт закрыт F5-вафом с JS-челленджем и FortiGate IPS, поэтому проверка идёт
через настоящий Google Chrome под Playwright (обычный headless-shell от
Playwright блокируется — нужен именно Chrome).

Цикл одной проверки:

1. `GET /icpplus/citar?p=43` — страница провинции, попутно проходится
   JS-челлендж F5.
2. `GET /icpplus/acInfo?tramiteGrupo[1]=4112` — сразу нужный трámite,
   минуя всю возню с выпадающими списками.
3. Кнопка **Entrar** → форма личных данных (NIE + имя, поля запрещают вставку,
   поэтому текст набирается посимвольно).
4. Кнопка **Solicitar Cita** (`enviar('solicitud')`) → страница `acCitar`.
5. Разбор результата **по структуре, а не по тексту**:
   - есть `#idSede` (список офисов) или радиокнопки слотов → **слоты есть**,
     летит уведомление с перечнем офисов;
   - текст `no hay citas disponibles` → слотов нет.

Проверка по структуре — не педантизм. Ловля точной фразы
`Seleccione la oficina donde solicitar la cita` давала ложные «слотов нет»:
на реальной странице написано просто `Selecciona Oficina`, и монитор
**доходил до свободных слотов, но не узнавал их**.

Ещё одна тонкость: переходы ждут полной загрузки ресурсов, а не только
`domcontentloaded`. Поведение страницы живёт в JS-бандле, и через VPN он
приезжает заметно позже HTML — без ожидания `enviar()` ещё не существует
в момент вызова.

Дату бот не сообщает: она видна только на следующем шаге, а тот уже
запускает бронирование и придерживает слот на 5 минут. Бот туда не заходит.

## Расписание

GitHub сильно занижает приоритет частых cron-расписаний, поэтому используется
один самозацикленный job: он крутится внутри себя до ~6 часов
(`LOOP_MINUTES=350`), проверяя раз в 5 минут, и перезапускается ежечасным
cron'ом как страховка. `concurrency: cancel-in-progress` не даёт им
наслаиваться.

Интервал 5 минут выбран не из вежливости, а по замерам: при темпе ~2.2 минуты
блокировка прилетала стабильно, даже со свежего испанского адреса. Три минуты
оказались слишком близко к этой границе.

`probe.yml` — отдельный диагностический workflow: перебирает другие trámite,
чтобы проверить ветку «слоты есть» на записи, где слоты обычно свободны.
Живёт в **своей** concurrency-группе: диагностика не должна убивать монитор.

## Секреты

Все чувствительные данные живут в **GitHub Secrets**, в репозитории их нет:

| Secret | Что это |
|---|---|
| `NIE` | NIE заявителя |
| `FULL_NAME` | Имя и фамилия как в заявке |
| `TELEGRAM_TOKEN` | Токен бота от @BotFather |
| `CHAT_IDS` | ID получателей через запятую |
| `OVPN_CONFIG` | `.ovpn`-конфиг испанского сервера целиком |
| `OVPN_USER` / `OVPN_PASS` | service credentials VPN-провайдера (не логин от аккаунта) |
| `PROXY_SERVER` | *(альтернатива VPN)* испанский HTTP/SOCKS-прокси |
| `PROXY_USER` / `PROXY_PASS` | *(необязательно)* авторизация прокси |

## Почему нужен VPN

Сайт принимает соединения **только с испанских IP** — с американского адреса
раннера GitHub он не отвечает вовсе (90 секунд таймаута против 0.9 секунды с
испанского IP). Поэтому job поднимает OpenVPN-туннель до испанского сервера.

Туннель **раздельный**: `route-nopull` отбрасывает все маршруты, которые
пушит сервер, и вручную добавляется только подсеть сайта `185.73.174.0/24`.
Собственный трафик раннера до GitHub идёт напрямую и не рискует оборваться.
Конфиг от провайдера можно класть в секрет как есть — строка `auth-user-pass`
заменяется автоматически.

### Выбор выходного узла

Сайт отклоняет запросы **подсетями /24**, а не отдельными адресами, поэтому
прыгать внутри одного блока бесполезно — все соседи отвергнуты тем же
правилом.

`pick_server.py` сознательно **не** использует `/servers/recommendations`: тот
отдаёт ~15 хостов, почти все в `187.13.x.x` — крупнейшем испанском блоке Nord
и, судя по всему, давно знакомом сайту. В полном списке 121 сервер в 23
подсетях. Выбирается сначала подсеть, потом хост внутри неё, поэтому блок из
трёх серверов конкурирует с блоком из тридцати девяти на равных.

Подсети, на которых прилетел отказ, `rotate_vpn.sh` записывает в файл, и
дальше они пропускаются.

### Поведение при блокировке

Заблокированный адрес остаётся заблокированным надолго, поэтому пережидать
невыгодно — уходит почти всё окно наблюдения. Вместо этого монитор
переподключается через другую подсеть и возвращается к проверкам за минуту.
Экспоненциальный отход остаётся запасным вариантом, если переподключиться не
удалось.

Подключение перебирает до пяти узлов и различает два отказа: отвергнутый
логин (`AUTH_FAILED` — дело в учётке или лимите сессий NordVPN) и узел,
который не поднял маршрут.

У NordVPN в кабинете WireGuard-конфига нет, только OpenVPN: страница сервера →
**Get setup configuration** → OpenVPN → **Download UDP**. Логин и пароль — это
отдельные **service credentials** по ссылке с той же формы, а не логин от
аккаунта Nord.

## Запуск локально

```bash
pip install -r requirements.txt
NIE=X1234567Z FULL_NAME="IMYA FAMILIYA" \
TELEGRAM_TOKEN=... CHAT_IDS=... \
python check.py
```

Без `LOOP_MINUTES` делается одна проверка и скрипт завершается.

## Управление

```bash
gh workflow run monitor.yml --repo <owner>/cita-monitor
```

Одиночная диагностическая проверка (покажет IP раннера и результат):

```bash
gh workflow run monitor.yml --repo <owner>/cita-monitor -f single_check=true
```

Остановить: отменить текущий run **и** выключить workflow — одного
`disable` мало, уже запущенный цикл он не прервёт.

```bash
gh workflow disable monitor.yml --repo <owner>/cita-monitor
```

## Другие провинции и трámite

`PROVINCE` — код провинции (Таррагона = 43), `TRAMITE` — код из выпадающего
списка. Для Таррагоны список полицейских трámite лежит в `tramiteGrupo[1]`;
в части провинций (Барселона, Мадрид, Малага, Севилья, Мелилья) индекс и
категория URL отличаются — см. `CATEGORY` / `TRAMITE_PARAM`.

Второй украинский трámite в Таррагоне:
`4111` — POLICÍA - UCRANIA : SOLICITUD PROTECCIÓN TEMPORAL DESPLAZADOS.
